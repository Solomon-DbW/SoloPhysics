# Dependencies
+ base-devel (Compiler toolchain and common build utilities)
+ cmake      (Generates build instructions for the project)
+ ninja      (Executes builds efficiently)
+ git        (Tracks source code history)
+ glfw-x11   (Provides a window and input handling through GLFW on X11 display server)
+ glm        (Supplies vector, matrix and geometric mathematics but doesn't automatically perform physics calculations)
+ mesa       (Provides open-source graphics drivers and implementations)
+ libglvnd   (Provides the vendor-neutral OpenGL dispatch library)
