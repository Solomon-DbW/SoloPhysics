# SoloPhysics Documentation - Obsidian vault

**Documentation snapshot:** 31 October 2026.

1. Extract `SoloPhysics-Obsidian-Vault.zip` anywhere, e.g. `~/Documents/SoloPhysics-Docs`.
2. In Obsidian use **Open folder as vault**, selecting `SoloPhysics-Obsidian-Documentation`.
3. Start at [[00 - SoloPhysics Documentation Hub]].
4. Equations use Obsidian/MathJax `$...$` or `$$...$$`; source uses fenced blocks, wiki links and Mermaid.
5. Use the **Print Edition** directory for the compiled PDF, source LaTeX and print-friendly Markdown.

**Boundary:** v0.4 source snapshots originated from the GLAD upgrade bundle; they are not a complete copy of the local repository. See [[19 - Bibliography and Attribution]].
